どこに貼ればいいの？（簡単ガイド）

  • HTML で作られているサイト:
    サイトの全ページの <head> タグの直後に貼り付けてください。
  • WordPress の場合:
    お使いのテーマの「アクセス解析設定」または「Site Kit by Google」「Header and Footer Scripts」等のプラグインの Head 欄に貼り付けます。
  • STUDIO / Wix / Shopify などのノーコードツール:
    管理画面の設定にある「外部アクセス解析」「カスタムコード挿入（head）」に測定ID（G-XXXXXXX）またはコードを貼り付けます。

Google アカウント連携設定

OAuth クライアント ID の取得手順（無料・約3分）

Google アナリティクスに直接アクセスして自動設定やデータ閲覧を行うため、あなた専用の Google Cloud「クライアント ID」が必要です。

  1. Google Cloud Console を開く
    Google Cloud Console（認証情報）を開く ↗ ※ 初めての場合は画面上部で「プロジェクトを作成」（名前: GA4よみやすい 等）を行ってください。
  2. 「+ 認証情報を作成」>「OAuth クライアント ID」をクリック
    ・アプリケーションの種類: 「ウェブ アプリケーション」 を選択
    ・名前: GA4よみやすい（何でもOK）
  3. 「承認済みの JavaScript 生成元」に現在のURLを登録
    下のURLをコピーして「URI を追加」に貼り付けます：
  4. 発行された「クライアント ID」を下の入力欄に貼り付け
    作成完了画面に表示される xxx.apps.googleusercontent.com をコピーして、下の枠に貼り付けて「保存して適用」を押せば完了です！

Google API 権限エラーの解決ガイド

解決手順（上から順にご確認ください）

① Google Cloud で API が「有効」になっていますか？（一番多い原因）

Google Cloud で以下の2つの API が有効化されていないと、Google から 403（権限なし）エラーが返されます。下のボタンをクリックして、青い「有効にする」ボタンを押してください。

① Admin API を有効にする ↗ ② Data API を有効にする ↗
② Google ログイン時にチェックボックス（権限）を許可しましたか？

Google ログイン画面で「Google アナリティクス データの表示と管理」というチェックボックスのチェックを外したままログインすると権限エラーになります。一度ヘッダーから「ログアウト」し、再ログイン時にチェックを入れてください。

③ Google アナリティクスアカウントに対する編集権限はありますか？

初期設定ウィザードで新規プロパティを作成する場合、選択した Google アカウント側で「管理者」または「編集者」権限が必要です。「閲覧者」権限のみのアカウントでは作成できません。
